# glavtrud-support

Публичные страницы приложения **Главтруд** — счётчика активности ввода для macOS,
оформленного как ведомость учёта труда. Исходный код приложения лежит отдельно
и закрыт; здесь только то, что должно быть доступно снаружи.

| Страница | Адрес | Зачем |
|---|---|---|
| `index.html` | `/` | Витрина: что это за приложение. Сюда же наращивается маркетинг |
| `support.html` | `/support.html` | Support URL для App Store Connect |
| `privacy.html` | `/privacy.html` | Privacy Policy URL, обязательное поле карточки |

Обращения принимаются в Issues этого репозитория — на них же ссылаются обе
страницы.

## Как устроено

Статика без сборки и зависимостей: три страницы и один `style.css`. Файл
`.nojekyll` отключает Jekyll, поэтому GitHub Pages отдаёт файлы как есть.

Вёрстка повторяет типографику приложения: три краски (бумага `#f7f1e3`, тушь
`#171310`, сигнальный красный `#c1272d`), нулевой радиус, двойная линейка ГОСТ
под рубриками. Тёмная тема включается по `prefers-color-scheme`.

Новая маркетинговая страница добавляется одним файлом рядом с остальными:
`<link rel="stylesheet" href="style.css">`, красная плашка `.band` сверху,
содержимое в `main > .wrap`.

## Правки

Меняете файл, коммитите в `main` — Pages пересобираются сами за минуту.
Политику конфиденциальности при этом надо держать в согласии с
`PRIVACY.md` в репозитории приложения: расходиться им нельзя.
