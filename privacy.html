Glavtrud · version 1.0

Privacy policy

Last updated: September 7, 2026.

In short

Glavtrud collects nothing about you. Everything the app counts stays on your computer. The app has no network entitlement and could not send anything anywhere even if it wanted to. The developer receives nothing from it.

What the app reads

Glavtrud counts your input activity in order to show it back to you as a labor record. It reads:

  • aggregate system event counters — how many key presses, clicks, scrolls and mouse movements have occurred. This uses the public system call CGEventSource.counterForEventType, which returns the number of events, not their content;
  • the bundle identifier of the frontmost application — to show which programs the time went to;
  • the time of those events, to the minute.

What the app does not read

  • Which keys you pressed. The program physically cannot see them: it does not use CGEventTap and does not request the Input Monitoring permission, without which key content is unavailable.
  • Window titles, page addresses, document contents, the clipboard. That would require the Accessibility permission, which the app does not request.
  • The screen image. Screen recording permission is not requested.
  • Your name, email, device identifiers, location.

Permissions

The app requests no system permissions at all.

Where the data is stored

In an SQLite file on your computer:

~/Library/Containers/com.di0niz.glavtrud/Data/Library/Application Support/Glavtrud/

The file is not encrypted and is not uploaded anywhere by the app. It will end up in your backups if you back up your home folder, like any other file.

Sharing with third parties

None. The app has no network entitlements, contacts no servers, and uses no analytics, advertising, crash reporting or third-party SDKs.

How to delete your data

Right-click the menu bar icon → Settings → "Delete all records…". The shifts, the record and the workshop assignments are gone for good; counting continues from that minute.

To remove everything, delete the directory above, or the app together with its container. No copies exist anywhere outside your computer.

Export

The app can export a CSV report. It saves the file wherever you point it. What happens to that file afterwards is up to you; the app never touches it again.

Children

The app is not directed at children and collects no data about anyone, children included.
