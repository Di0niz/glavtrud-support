The numbers are empty

The app counts from the moment it starts, and a minute counts as active only if some input happened in it. The first numbers appear after a few minutes of real work. The quota is assigned after five worked shifts; until then the app is on probation and shows no quota at all.

Where is my data

In a single SQLite file inside the app's own container:

~/Library/Containers/com.di0niz.glavtrud/Data/Library/Application Support/Glavtrud/

Nothing is sent anywhere. The app has no network entitlement, so it could not send anything even if it wanted to.

How to export or erase everything

Right-click the menu bar icon. Labor report, CSV… writes the whole record wherever you point it. Settings → Delete all records… erases the shifts, the record and the workshop assignments for good; counting continues from that minute.

Why does it not see my work

The app counts input events, not thinking. Reading, watching and meetings produce no keystrokes and no clicks, so they produce a shortfall — and that shortfall is correct. Glavtrud measures input load, not the value of your work.

Where is the window

There is none at launch: Glavtrud lives in the menu bar and has no Dock icon. Left-click the icon for the shift card, right-click for the menu, "Open personal file" for the full report.

Privacy

The app requests no system permissions and reads aggregate event counters, never the content of your input. See the privacy policy.
